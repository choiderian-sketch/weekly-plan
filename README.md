# 주간 예정사항 작성기

부대의 「주간 예정사항」을 2페이지(이번 주 상세 예정사항 + 향후 4주 월력표)로 작성하고 A4로 인쇄하는 웹 프로그램입니다.

## 주요 기능

- 자연어 일정 입력 (예: "10월 27일 14시 대대 회의실에서 간부 대상 안전교육")
  - 날짜·시간·장소·대상·주관·비고를 자동으로 나누고, 저장 전에 검토·수정
  - 연도·오전/오후·요일이 모호하면 경고 표시
- 항목별 입력, 수정·삭제·복사·날짜 이동, 검색·기간 필터
- 1페이지: 이번 주 상세 예정사항 표 (순서 조정, 상세 내용, 준비·특기사항)
- 2페이지: 월요일 시작 월력표, 이번 주 강조, 일정은 개조식 1~2줄
- A4 인쇄 (1페이지 세로, 2페이지 가로), 넘치면 글자 크기 자동 축소
- 브라우저 로컬 저장, JSON 백업·복원, CSV 내보내기·가져오기
- Supabase 로그인 시 클라우드 저장 (사용자별 문서, Row Level Security로 본인만 접근)

## 기술

- HTML, CSS, JavaScript 단일 파일 (`index.html`)
- 로그인 전: 브라우저(localStorage)에만 저장
- 로그인 후: Supabase `weekly_plans` 테이블에 저장 (supabase-js, 이메일·비밀번호 인증)
- 배포: Vercel (정적 사이트)

## 실행

- 로컬: `index.html`을 Chrome 또는 Edge로 열기
- 배포: GitHub 저장소를 Vercel에 연결 (별도 빌드 설정 없음)
